## Featured Work

### `>` AI SOC Digital Teammate
An autonomous, agent-based system designed to augment human SOC analysts across **threat detection and response**. The platform automates alert triage, telemetry enrichment, and investigation workflows — pushing toil down and freeing analysts to focus on judgment, correlation, and decision-making. Built with reliability, auditability, and human-in-the-loop control as first-class design constraints.

> **Stack:** Python · LLM agents · Detection logic · SIEM integrations · Kafka · Redis · PostgreSQL · FastAPI

### `>` Distributed Video Analytics Platform
A horizontally scalable platform delivering **object detection, tracking, and segmentation** across heterogeneous use cases — from retail store analytics to industrial automation. Architected around Kafka-decoupled ingestion, GPU-distributed inference, stateful processing with retry/resume semantics, and a reusable multi-core scheduler that drives consistent throughput across deployments.

> **Stack:** Python · YOLO · Ultralytics · PyTorch · Kafka · GPU clusters · FastAPI · Docker
